# AnyModel: таблица моделей (Chrome)

Chrome-расширение (MV3) для [anymodel.org](https://anymodel.org): заменяет каталог карточек быстрой таблицей моделей — цены ($/1M токенов), контекстное окно, live-статусы доступности и uptime. Многокритериальная сортировка (клик + Shift+клик), фильтры по типу/статусу/ctx/цене, пресеты («дешёвая + широкий ctx + работает»). Данные не собирает.

Требуется вход на anymodel.org — расширение использует сессию пользователя для запросов к API сайта.

## Возможности

- **Быстрая таблица** вместо тормозящих карточек: модель, провайдер, тип, $/1M вход/выход, ctx, max out, возможности (Vision/Tools/Search/Reasoning/…), статус, uptime
- **Многокритериальная каскадная сортировка**: клик по колонке — критерий №1, Shift+клик — добавить №2/№3, повторный Shift+клик — убрать
- **Фильтры**: поиск, тип (LLM/Фото/Видео/Аудио), доступность (работает / +нагрузка / только сбои), ctx ≥ N (понимает `128K`, `1M`), цена входа ≤ N
- **Пресеты**: «Дёшево + широкий ctx + работает», «Максимальный ctx», «Самая дорогая», «Бесплатные»
- **Окно аптайма** 6ч/12ч/24ч/7д; 7д — серверное значение, короче — честная оценка по часовой решётке статуса
- Статусы производных моделей (`-review`, `-medium`/`-low`) наследуются от базовой модели линейки
- Автообновление статусов раз в 2 минуты, настройками фильтров запоминаются
- Кнопка «⟨ Карточки» возвращает оригинальную страницу

## Установка (unpacked)

1. `chrome://extensions` → включить режим разработчика
2. «Load unpacked» → выбрать папку расширения
3. Открыть [anymodel.org/app/model-catalog](https://anymodel.org/app/model-catalog), войдя в аккаунт

## Как это работает

Расширение не парсит DOM: оно запрашивает те же JSON-API, что и сам сайт, в контексте вашей сессии:

- `GET /api/me/models?kinds=llm,decision,image,video,audio` — каталог (ctx, цены-коэффициенты, возможности)
- `GET /api/status/models` — статусы доступности и uptime за 7 дней

Цена = коэффициент × $0.05 за 1M токенов (базовая ставка AnyModel).

## Приватность

Расширение не собирает, не хранит и никуда не передаёт данные пользователя. Все запросы идут только на `anymodel.org` в рамках сессии пользователя; в `chrome.storage.local` сохраняются лишь настройки таблицы (сортировка/фильтры).
